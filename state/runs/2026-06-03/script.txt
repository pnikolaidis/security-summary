Ada Iverson here. Wednesday's signal, coming up. Five stories today — one active exploitation mandate, a fresh Android patch you need to push, a nasty new denial-of-service technique affecting every major web server, a developer-facing zero-day with public exploit code, and a gaming-targeted malware campaign that has already claimed more than a hundred thousand victims.

Story one. CISA has added a two-year-old Oracle WebLogic Server flaw to its Known Exploited Vulnerabilities catalog after confirming active exploitation in the wild. The vulnerability, CVE-2024-21182, is a path-traversal issue that unauthenticated remote attackers can exploit against unpatched WebLogic instances — in some configurations it reaches all the way to code execution. Oracle patched this back in April 2024, but a significant number of production servers were apparently never updated. Federal civilian agencies now have until mid-June to remediate under a binding CISA directive, and that deadline is a good forcing function for everyone else too. If you're running internet-facing WebLogic and haven't applied the April 2024 Critical Patch Update, treat this as urgent — the patch exists and attackers are actively using this.

Story two. Google released its June 2026 Android security bulletin and it is a big one: one hundred and twenty-four vulnerabilities patched, including one that is already being exploited in targeted attacks right now. That actively exploited flaw is CVE-2025-48595, a high-severity elevation-of-privilege bug in the Android Framework component. Google says exploitation has been limited and targeted so far, but that can change quickly. The good news is patches are rolling out through Google Play system updates and OEM channels. The action item is simple: go check for updates on every Android device in your household or organization and apply them as soon as they appear. Don't wait for your carrier to push it.

Story three. Researchers have disclosed a new denial-of-service technique they're calling the HTTP/2 Bomb, and it affects essentially every major web server and proxy in their default configurations — NGINX, Apache HTTPD, Microsoft IIS, Envoy, and Cloudflare Pingora. The attack chains two known techniques: a compression bomb that inflates small payloads into enormous ones, combined with a Slowloris-style connection hold that keeps the server tied up processing them. The result is that an attacker with very limited bandwidth can take a server offline in seconds. There's a working proof-of-concept, vendors are aware, but patches are not fully available across all affected projects yet. If you run any of these web servers or proxies, watch your vendors' security advisories closely and audit your HTTP/2 configuration settings in the meantime.

Story four. A security researcher has released public exploit code for an unpatched Visual Studio Code zero-day that steals GitHub authentication tokens with a single click. The attack works by abusing VS Code's custom URI handler — a victim just needs to click a specially crafted link, and their GitHub token is silently exfiltrated to the attacker. With that token, the attacker gets full access to whatever GitHub repositories and organizations the victim can reach. Microsoft has been notified, but no patch has been confirmed or scheduled yet. In the meantime, developers should be cautious about clicking VS Code-related links from unknown sources, and organizations should consider reviewing GitHub token scopes and enabling alerts for unusual access patterns.

Story five. A malware campaign called WeedHack has been quietly infecting Minecraft players since January and has now compromised over a hundred and sixteen thousand systems. The operation runs as a malware-as-a-service platform — threat actors pay to use the infrastructure and then distribute payloads through YouTube video descriptions and fake mod download sites. The payloads include CountLoader, which has hit around eighty-six thousand systems on its own, as well as cryptocurrency miners that run silently in the background. This is a reminder that gaming communities are high-value targets for commodity malware, and that the people most at risk are often not security-aware adults but young gamers who won't think twice about clicking a "download mods here" link under a YouTube video.

That's your digest. Stay safe out there.
