Good morning. Here is your security digest for June 18th, 2026. It's a busy day for patches and a concerning one for Microsoft Defender users — one zero-day is still waiting for a fix.

Story one. Microsoft has confirmed a zero-day vulnerability in its Defender security engine, codenamed RoguePlanet, and the patch is still in development. The flaw has been assigned CVE-2026-50656 with a CVSS score of 7.8, and it allows an attacker to escalate their privileges on an affected system. Because Microsoft Defender is turned on by default across virtually every modern Windows machine, the exposure here is enormous. Microsoft hasn't confirmed active exploitation yet, but the zero-day designation means researchers and attackers have detailed knowledge of the flaw. Until the patch ships, security teams should keep a close eye on unusual behavior from the Defender engine process and layer on additional endpoint controls where possible.

Story two. Both Splunk and Atlassian pushed critical security patches this morning. Splunk fixed an OS command injection vulnerability in its AI Toolkit component — that's the kind of flaw where an attacker can run arbitrary commands directly on the server running Splunk. Atlassian's release is broader, addressing dozens of vulnerabilities in third-party library dependencies spread across its product suite. Splunk and Atlassian are central to how most large enterprises run their DevOps pipelines and security operations centers, so these patches should move quickly to the top of the queue. If you're running Splunk's AI Toolkit in particular, that one should not wait.

Story three. Security researchers have detailed a new Android banking trojan called Rokarolla, and it's a broad one — it targets more than two hundred financial and banking applications. Once installed, Rokarolla gives attackers full remote control over the infected device, and on top of that it harvests credentials for all those banking apps. The combination of full device takeover and credential harvesting across hundreds of financial apps makes this a serious threat for mobile banking users. Organizations with bring-your-own-device policies should check whether their mobile threat defense solutions have been updated to detect this family, and employees should be reminded to only install apps from official stores.

Story four. Cisco patched a critical vulnerability in Identity Services Engine, which is the platform many enterprises rely on to control who gets access to their networks. The flaw comes down to insufficient validation of user input, and it lets an authenticated attacker run arbitrary commands on the underlying operating system and escalate all the way to root. If an attacker already has a foothold on your network — or compromised account credentials — getting root on the authentication backbone is a serious situation. This one allows full infrastructure access. Cisco has released patched versions, and organizations should apply them as quickly as possible, especially those whose ISE admin interface is reachable from inside the network.

Story five. Microsoft's June Patch Tuesday rollout introduced two separate problems. First, Windows Server 2016 systems that weren't fully up to date failed to install the June security updates at all — silently. That means many patch management dashboards are showing these servers as compliant when they are not. Microsoft has issued a fix for this specific issue. Second, a separate bug introduced by the June updates is preventing third-party applications from launching Microsoft Office or opening Office documents on fully patched Windows systems. That second issue is still under investigation. For security teams, the takeaway is straightforward: do not assume your patch reports are accurate right now. Manually verify update installation status on Server 2016 hosts, and investigate any help-desk reports about broken Office integrations.

That's your digest. Stay safe out there.
