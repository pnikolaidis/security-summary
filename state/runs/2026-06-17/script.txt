Good morning. Here is your security digest for Wednesday, June 17th, 2026. Ada Iverson here. Wednesday's signal, coming up. Today's five stories span an actively exploited maximum-severity CMS flaw with a federal patching deadline, a wave of critical browser patches, an unpatched Windows Defender zero-day with public exploit code, a ransomware group turning Microsoft Teams into a covert channel, and a malware campaign targeting developer AI keys through fake IDE plugins.

Our top story: federal agencies have until Friday to patch a maximum-severity vulnerability in the Joomla Content Editor plugin, and the clock is ticking. CVE-2026-48907 is a CVSS ten-point-zero improper access control flaw in the Widget Factory JCE plugin — one of the most widely installed extensions for Joomla-based websites. CISA added it to the Known Exploited Vulnerabilities catalog on Tuesday after confirming it is already being actively exploited in the wild. The attack requires no authentication: an adversary can reach directly into the plugin's file-upload functionality and drop a PHP webshell, taking full control of the server. A companion LiteSpeed vulnerability is also being exploited in the same campaigns to gain root on shared hosting environments. If you run a Joomla site or manage any CMS infrastructure, this one cannot wait.

Our second story: both Firefox and Chrome shipped urgent updates yesterday, and the Firefox release is particularly serious. Mozilla's Firefox 152 and ESR 140.12 patch three critical CVEs. CVE-2026-12304 is a same-origin policy bypass in the browser's networking and cookies component, meaning a malicious page could silently read data from a different site. CVE-2026-12315 and CVE-2026-12316 are mitigation bypasses in the DOM security layer, and the full ESR 115 line also received memory safety patches. Google's Chrome update in the same window addresses critical and high-severity memory safety bugs that could lead to remote code execution. If you have not restarted your browser in the last 24 hours, do it now.

Our third story: a zero-day in Microsoft Defender is sitting unpatched with working exploit code already public. Nicknamed RoguePlanet and tracked as CVE-2026-50656, it is an elevation of privilege in the Microsoft Malware Protection Engine. The exploit takes advantage of a race condition to spawn a command prompt running with full SYSTEM privileges — the highest level on a Windows machine. The vulnerability was disclosed about a week ago, and a proof-of-concept has been circulating since then. Microsoft confirmed the issue is real and says a patch is in progress, but gave no timeline. Until the fix arrives, every Windows system running Defender is carrying a local privilege escalation risk that any attacker who has already gotten a foothold could use to fully own the machine.

Our fourth story: ransomware operators from the DragonForce group have found an inventive way to hide their command-and-control traffic. Incident responders uncovered a new Go-based backdoor that connects to Microsoft Teams relay servers rather than attacker-owned infrastructure. Because the traffic looks identical to legitimate Teams collaboration traffic at the network level, traditional perimeter defenses that allow Teams through the firewall cannot distinguish the malicious communications. This is a meaningful escalation for the group — it shifts the detection burden entirely to endpoint tools and behavioral analysis. If your organization uses Microsoft Teams, ensure your endpoint security can inspect Teams process behavior, not just network traffic.

Our fifth story rounds out the day with a threat aimed squarely at software developers. Researchers discovered at least 15 malicious plugins on the JetBrains Marketplace, all posing as AI-powered coding assistants built on DeepSeek and similar models. The plugins offered convincing features — chat, automated commit messages, code review, bug detection — while in the background they hunted for AI provider API keys stored in the IDE environment and quietly exfiltrated them. A related campaign was simultaneously planting Chrome extensions to capture AI chatbot conversations. Developer API keys for services like OpenAI, Anthropic, and others are valuable targets: they carry billing access and can be used to run expensive inference workloads or extract proprietary prompts. JetBrains has been notified. If you installed any new AI assistant plugin recently, pull it, check the publisher, and rotate your keys.

That's your digest for Wednesday, June 17th. Patch Joomla before Friday, update your browsers today, watch for the Defender fix, keep an eye on Teams traffic anomalies, and audit your IDE plugins. Stay safe out there.
